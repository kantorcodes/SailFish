## 怎么做

**标准题（冻住）**

- 题版本写死为 `sailfish-bench-v2`，报告里照抄。
- 中文拟真：冻住的完整系统说明 + 完整工具清单 + 像真任务的用户话（内容锁死，不是运行时提示词/工具表）+ 只许回一句短话。
- 分档按字数垫用户侧；发出去之后以接口返回的输入 token 为准记进报告。超窗口按估出来的 token 对照窗口跳过。
- 2026-09-21：每一档题头带自己的档位标记，填充单元也带档位，避免短档是长档的前缀、接口把上一档提示缓存吃到下一档。

**默认梯子**

- `4000 / 16000 / 32000 / 64000 / 128000`。不自动打到窗口边上。
- 用户也可自填几档；不填走梯子。

**一次请求**

- 走现有流式+工具调用，指定选中的模型配置。
- `max_tokens` 收得很小（几十到一百），指令也限制只回短句，避免生成长短把耗时搅乱。
- 关掉这场的自动重试、自动换模型。429 / 超时 / 截断 / 断流都记。
- 量：成功与否、首字时间、整轮时间、结束原因、是否限流、是否截断、接口返回的输入/输出 token。

**独立窗口**

- 新窗口，菜单里和「AI 调试控制台」并列。
- 选已有模型、长度档（默认梯子 / 自填）、开始、停止、进行中的当前档、完成后的表、复制 JSON / 保存文件。
- 进度推到这个窗口；可中途停，已打完的档留在表里。
- 调试窗口不改；压测请求若走同一套底层，调试开着时仍会记到流水里（旁观，不是同一块屏）。

**报告 JSON（便于两份对着看）**

- 题版本、开始/结束时间、模型名、接口地址、窗口大小、冻住的温度、各档：目标长度、实际输入 token、成败、首字/整轮毫秒、结束原因、错误、是否限流、是否截断。
