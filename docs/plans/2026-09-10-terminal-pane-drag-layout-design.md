2026-09-10 终端窗格拖拽排放

## 要解决什么

终端页里多扇本机 / SSH 窗格只能靠菜单或快捷键分屏，分好之后不能拖着换位置。用户要第一档：铺满拼在一块，用拖拽排放；已打开的标签不合并进另一扇。

## 用户能感知的结果

1. 已经并排的窗格：抓住顶上的机器名，拖到另一扇的上 / 下 / 左 / 右，换位置。
2. 主机列表里拖一台到眼前窗口的边上，松手就在那边先出窗格、显示正在连接，再连上（缺凭证仍走原来的询问）。连不上在那一扇里说，不弹超时框。
3. 标签栏「+」拖到眼前窗口的边上，松手就在那边新开一扇本机终端；点一下仍是新标签。
4. 已打开的终端标签只能换顺序，不能拖进窗口里合并。
5. 助手对话页没有这套拖拽。
6. 同一方向并排均分（三扇就是各约三分之一），不要一层层把眼前那扇切成一半。换方向才在那一格里切开。

## 不做

- 浮动 / 重叠 / 撕成独立系统窗口
- 把已打开的标签吸进当前分屏
- 跨标签把一扇窗格拖到另一页

## 怎么做

- 窗格树纯函数：按边切开、把已有叶节点搬到另一叶的边上；用连接标识（不是布局节点 id）在搬移后重新找到目标，避免压缩层级后找错。
- 店里：搬移已有窗格；按边新开本机或指定主机。
- 窗格界面：拖拽进行中才露出四边落点；机器名是抓手。
- 主机列表 / 「+」开始拖时记下「正在拖什么」，窗格只认这个，不靠拖拽文本。
