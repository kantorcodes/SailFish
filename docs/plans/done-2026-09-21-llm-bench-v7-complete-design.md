# 压测做完善（题升 v7）

> 落盘日期：2026-09-21
> 状态：已完成

## 为什么

尺子要能横比：题冻住、数字诚实。窗口没填会悄悄当 12.8 万；写速把思考算进去；没照抄写长了会抬高写速分；模型配置里的输出上限会把工具/并发卡成假失败。

## 定下的取舍

1. **并发仍是桌上三路**，不做成高并发扫表。压私有算力的一路加到打挂，用现成专门工具（GuideLLM / vLLM bench / AIPerf）。
2. **没填窗口就不开跑**，不猜 12.8 万。
3. **写速按正文算**；没照抄的档不计入写速分。
4. **输出额度由压测冻住**，不听模型配置里可能很小的那个上限。
5. **发数只认 1 / 3 / 5**，写了别的数就不开跑，不悄悄改成 3。
