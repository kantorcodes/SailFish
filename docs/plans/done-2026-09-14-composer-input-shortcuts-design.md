# 2026-09-14 消息输入快捷键可自定义

已完成

设置 → 快捷键能自己录「发送」和「排队」。默认仍是回车发送、⌘/Ctrl+回车排队。只在输入框生效。

## 取舍

- 换行不单独设：没被占用的回车（含 Shift+回车）就是换行
- 不进菜单、不当全局快捷键
- 发送和排队会抢同一下按键时，设置里拦住
- 不做：引导向导小对话、远程网页会话、文件管理器传输键

- [x] 配置补上发送 / 排队两条，缺省补默认值
- [x] 快捷键设置页增加「消息输入」分组，允许单独录回车
- [x] 输入框按配置发送 / 排队，提示跟着实际按键走
- [x] 单测覆盖回车匹配和冲突判断
