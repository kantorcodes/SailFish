## 要解决的问题

画行情、K 线时，整份数组被反复灌进对话，撑爆后点「继续」又原样重发。

## 取舍

- 画图的文件路径入口沿用周思远的用法（路径与内联二选一，检查文件只看结构）。
- 预算公式沿用：能发的输入先扣这次输出额度和一点余量；指定配置找不到时按保守窗口估，不借另一套模型的大窗口。
- 发送前检查、相同大段工具结果改为引用：按我们现有压缩和长输出落盘来做，不猜「这是不是图表」。
- 这轮不做：独立归档目录、给旧失败会话预埋交接、重写整段流式超时。

## 用户能验收的结果

1. 数据已经在文件里时，画图只报路径，完整数组不进对话。检查文件只看到字段、条数、路径。
2. 内联数据和路径必须二选一，不能两个都空、也不能两个都给。
3. 同一段足够长的工具原文还在这场对话里，再读一次只得到引用；原文已被压缩拿走、或内容和上次不一样，仍正常返回。
4. 关掉再打开一场已经过大的对话，第一句先压，压完还超就拦。
5. 指定的模型配置找不到时，按保守窗口估。
